# 리소스·대사 수정 안내

모든 리소스는 `Assets/StreamingAssets/Content/base/` 아래에 **보통 파일**로 있습니다(빌드하면 `Build/Win/Farland_Data/StreamingAssets/Content/base/`).
고친 뒤 Unity 에서 Play 를 누르거나, 빌드한 게임을 다시 실행하면 바로 반영됩니다. 다시 빌드할 필요가 없습니다.
Unity 메뉴 **Farland ▸ 리소스 ▸ 콘텐츠 폴더 열기** 로 이 폴더를 열 수 있습니다.

## 무엇을 고치려면 어느 파일

| 바꾸려는 것 | 파일 | 도구 |
|---|---|---|
| 맵 지형 | `Maps/STAGE01.tmj` … `STAGE14.tmj`, `STAGE62.tmj`(6장 썰물 뒤) | [Tiled](https://www.mapeditor.org) |
| 지형 타일 그림 | `Tilesets/MAPCHIP_tiles/000.png` …(14장은 `MAPCHIP2_tiles`) | 그림 편집기 |
| 아군 캐릭터 그림(맵·얼굴·전투) | `Characters/01/` … `Characters/16/` | 그림 편집기 |
| 적·클래스 공통 그림 | `Sprites/MAPCHAR/NNN.png`(맵), `SpriteDefs/CHAR_NN_frames/000.png`(전투) | 그림 편집기 |
| 얼굴(아군 외) | `Sprites/FACE17.png` … | 그림 편집기 |
| 대사 문장 | `Dialogue/STAGE01.tsv` … 의 **고친 대사** 칸 | 구글 시트·VS Code |
| 고유명사(이름·클래스·아이템) 일괄 | `Config/glossary.json` | 메모장·VS Code |
| 메뉴·메시지 문구 | `Config/strings.json` | 메모장·VS Code |
| 장 제목·이벤트 순서 | `Config/stages.json` | 메모장·VS Code |
| 능력치·아이템·유닛 배치 | `Battle/battle_data.json` | 메모장·VS Code |
| 음악·효과음 | `Audio/BGM/trackNN.ogg`, `Audio/SFX/*.wav` | 같은 이름으로 바꿔 넣기 |
| 창·글꼴·커서 | `UI/*.png`, `Fonts/*.HAN·ENG`, `Sprites/MCSRFONT/` | 그림 편집기 |

## 맵 (Tiled)

1. [Tiled](https://www.mapeditor.org) 를 설치하고 `Maps/STAGE01.tmj` 를 엽니다. 타일셋(`Tilesets/MAPCHIP_tiles.tsj`)은 자동으로 붙습니다.
2. 오른쪽 타일셋 창에서 타일을 골라 칠하고 **저장**(Ctrl+S)합니다. 형식은 그대로 `.tmj`(JSON)여야 합니다.
3. 맵은 원작처럼 **짝수 행이 반 칸 오른쪽**으로 밀린 엇갈림 배치입니다(Tiled 의 육각 맵으로 열림).

- 타일 번호 = 원작 맵칩 번호입니다. 칩마다 정해진 **지형 효과**(이동 비용·방어)는 `Battle/battle_data.json` 의 `chipTerrainMAPCHIP`(14장은 `…MAPCHIP2`)를 따릅니다. 새 그림을 그린 칩은 같은 번호의 지형으로 동작합니다.
- **맵 크기(가로·세로)는 바꾸지 마세요.** 유닛 배치·이벤트 좌표가 원작 좌표 그대로입니다.
- 대본이 바꾸는 칸(문이 열림, 다리가 놓임 등)은 실행 중에 덮어씁니다. 그 칸을 칠해도 이벤트 뒤에는 대본대로 바뀝니다.
- 첫 번째 타일 레이어만 읽습니다. 메모용 레이어를 더 만들어도 됩니다.

## 캐릭터 그림

`Characters/NN/` — NN 은 이름 번호입니다.

01 아크, 02 란티아, 03 아리시아, 04 고달, 05 드카티, 06 디노, 07 리사, 08 루시다, 09 이완, 10 미리아, 11 아리나, 12 파미라, 13 윌, 14 카이, 15 멜, 16 훼리오

| 파일 | 내용 | 크기 |
|---|---|---|
| `map_c00.png` | 맵 그림(클래스 00일 때) | 32×32 |
| `map_acted_c00.png` | 행동을 마친 회색 그림 | 32×32 |
| `battle_c00/000.png …` | 전투 연출 프레임(0 대기, 1 피격, 2 쓰러짐, 3 누움, 그 뒤는 공격 동작) | 클래스마다 다름(`SpriteDefs/CHAR_00.json` 의 `frameWidth`×`frameHeight`) |
| `face.png` | 대화 얼굴 | 112×112 |

- 지금 그림이 **처음 클래스 번호**로 복사돼 있습니다(`_이름.txt` 에 클래스 번호). 전직하면 새 클래스 번호의 파일(`map_c03.png` 등)을 찾고, 없으면 클래스 공통 그림을 씁니다.
- 클래스와 상관없이 늘 같은 그림을 쓰려면 이름에서 `_cNN` 을 뺍니다: `map.png`, `map_acted.png`, `battle/000.png`.
- `map_acted…` 가 없으면 `map…` 을 어둡게 칠해 씁니다.
- 전투 프레임은 일부만 넣어도 됩니다. 없는 번호는 클래스 공통 그림을 씁니다. 기준점(발밑)은 클래스 정의(`pivotX`, `pivotY`)와 같습니다.
- 다른 캐릭터(적 이름 등)도 같은 규칙으로 `Characters/17/` 처럼 폴더를 만들면 됩니다. 단 '악마 군병' 처럼 여러 유닛이 같은 이름을 쓰면 그 이름의 유닛 전부에 적용됩니다.
- 폴더를 다시 만들려면 **Farland ▸ 리소스 ▸ 캐릭터별 그림 폴더 만들기**(이미 있는 파일은 건드리지 않음).

## 대사

### 문장 고치기: `Dialogue/STAGExx.tsv`

| 블록 | 줄 | 얼굴 | 원문 | 고친 대사 |
|---|---|---|---|---|
| 0 | 1 | 훼리오 | ［멜！ 빨리！］ | *(여기에 쓰면 이 문장으로 바뀜)* |

- **고친 대사** 칸만 채우세요. 비워 두면 원문 그대로입니다. 블록·줄 칸은 위치 정보이므로 바꾸지 마세요.
- 한 행이 화면의 한 줄입니다. 한 페이지는 최대 4줄, 한 줄은 한글 22자 정도까지 들어갑니다(넘치면 자동 줄바꿈).
- `［ ］`(전각 괄호)는 화면에서 원작처럼 「 」로 보입니다. 대사 시작·끝에 그대로 두면 원작 모양이 유지됩니다.
- 말하는 사람의 이름표는 문장이 아니라 장면의 유닛 이름에서 옵니다(아래 고유명사 참고).
- 편집 도구: **구글 시트**(파일 ▸ 가져오기 → 탭으로 구분 / 다운로드 ▸ .tsv) 또는 **VS Code**. 엑셀은 저장할 때 인코딩이 바뀔 수 있으니 **UTF-8** 로 저장되는지 확인하세요.
- 파일 구분: `STAGE01`~`STAGE14` 각 장(1장 파일에 프롤로그 포함), `STAGE51` 아이템 설명, `STAGE52` 상점 인사·명령 대사, `STAGE99` 에필로그. `STAGE02O`·`15`·`16`·`53` 은 게임에서 쓰지 않습니다.

### 고유명사 한꺼번에: `Config/glossary.json`

```json
{ "kind": "인물", "from": "아크", "to": "아크" }
```
- `to` 만 바꾸면 **대사 문장·이름표·클래스 이름·아이템 이름 전부**에서 바뀝니다(긴 말부터 바꾸므로 '다크 옐후' 와 '옐후' 를 따로 정할 수 있음).
- 인물·클래스·아이템 이름이 처음부터 들어 있습니다(지금은 모두 '그대로').
- 대화체(말투)는 용어집이 아니라 `.tsv` 의 고친 대사로 바꿉니다.

### 그 밖의 글자
- 메뉴·메시지(예: 'OO에게 20의 DAMAGE', '턴 종료'): `Config/strings.json`
- 장 제목: `Config/stages.json` 의 `title`

## 원본을 지키며 고치기(권장)

`base` 폴더는 `tools/build_content.py` 를 다시 돌리면 CD 추출본으로 덮어써집니다. 오래 둘 수정은 **새 팩**에 넣으세요.

```
Assets/StreamingAssets/Content/my_pack/pack.json       { "id": "my_pack", "priority": 10, "enabled": true }
Assets/StreamingAssets/Content/my_pack/Config/glossary.json
Assets/StreamingAssets/Content/my_pack/Dialogue/STAGE01.tsv
Assets/StreamingAssets/Content/my_pack/Characters/01/face.png
Assets/StreamingAssets/Content/my_pack/Maps/STAGE03.tmj
```
같은 경로의 파일은 우선순위가 높은 팩의 것이 쓰입니다. 바꾼 파일만 넣으면 됩니다(맵 `.tmj` 를 새 팩에 넣을 때는 `Tilesets/` 도 같이 복사해야 Tiled 에서 그림이 보입니다).
빌드한 게임에서는 `%USERPROFILE%\AppData\LocalLow\Prototype\Farland Story\Mods\my_pack\` 에 넣어도 됩니다.
